# Converter

Converts files between formats: video, audio, images, PDF, documents, e-books, archives.

## Install

Terminal agents:

```sh
npx skills add geragarazagh/converter -g
```

Claude Code:

```sh
claude plugin marketplace add geragarazagh/converter
claude plugin install converter@converter
```

Gemini CLI:

```sh
gemini extensions install https://github.com/geragarazagh/converter
```

Claude and ChatGPT apps: upload `converter.zip` from the [latest release](https://github.com/geragarazagh/converter/releases/latest).

Any other agent: paste the text of [`SKILL.md`](skills/converter/SKILL.md) into its instructions.
